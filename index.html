Horse Animation Editor

This editor allows you to create animations for the rigged horse model.

How to use:

  • Select a bone from the dropdown menu
  • Adjust rotation values using the sliders
  • Add keyframes at different points in the timeline
  • Scrub through the timeline to preview your animation
  • Use Play/Pause to see your animation in motion
  • Save your animation to reuse later

Tips: For natural movement, start with the main body parts (spine, neck) before animating legs and tail.
